# 学员筛选回归与 PDF 报告

用户已选择可下载报告版并要求直接实现。延续已展示的深绿、浅色企业报告风格，采用后端 PDFBox 生成可搜索文字的 A4 PDF；不截取网页、不依赖服务器浏览器。

1. 回归学员筛选：全部/个人、同名、无记录、部门交集、历史部门、企业隔离、学时和各明细、Excel 导出、逾期全选及通知范围。保留现有统计口径。
2. 新增 dashboard/report/export：读取已应用的时间/培训/部门/分类/学员条件；复用 DashboardService 的同一统计数据，全量培训汇总，不受 UI 页码影响。筛选名称需企业内解析；缺失或不属于本企业的选项拒绝。
3. PDF：概览指标、状态分布、近30天趋势、部门表、全部培训表、口径说明；页眉页脚、重复表头、长名称换行、空数据。中文字体随应用打包及附许可证。时长复用公共格式化方法。
4. 前端增加“下载 PDF 报告”，下载中防重复点击，失败明确提示，重置保留原逻辑；未点击查询的草稿不得改变报告条件。
5. 验证：服务单测、真实 MySQL 接口回归、PDF 文本和分页测试、渲染视觉检查、前端类型/测试/构建及本地浏览器。无邮件真实发送，无生产数据变更。
