# 培训材料预览预生成

PDF/图片保存后进入后台队列，每个应用实例同时转换一份材料。页面图片保存在原文件所属的对象存储中（EDS 或历史阿里云 OSS），仍由原有鉴权接口读取，不开放公共材料链接。

## 部署

- 后端部署时执行现有 Flyway 迁移 V51，只追加预览字段和索引，不清空业务数据。
- `deploy/database/init-schema-and-admin.sql` 仍是 V50 的首次安装快照；首次部署后由现有迁移机制继续执行 V51。不要在已有数据库上重复执行初始化脚本。
- 不需要新增生产环境变量。后台任务默认开启；`training.preview.enabled=false` 仅用于隔离自动化测试。
- 原有材料会自动进入队列逐个补生成。队列清空前，尚未处理的材料暂不能阅读，已有进度保留。建议在低峰部署；预留页面 PNG 所需的存储空间。

## 状态与恢复

- 等待生成 / 正在生成：管理页面每 5 秒刷新状态。学员打开尚未完成的预览会等待并重试，此时不累计阅读时间。
- 可阅读：只读取已保存的 PNG，不再下载原始 PDF 或重新转图。
- 生成失败：管理员点击“重新生成”。后台日志包含材料 ID 和异常；页面不展示内部连接信息。
- 重启恢复：数据库保存队列状态和逐页进度；MySQL 连接级命名锁防止多个实例重复处理同一材料。连接断开后锁自动释放，下一次轮询继续处理。
- 已完成页保留，未完成页复用预先保存的对象键，避免重试产生重复文件。
- 转换期间暂不允许删除；完成/失败后删除会尝试清理原件和所有已登记的页面对象。存储清理失败会记录日志，可能需要按日志清理遗留对象。

## 验证边界

本次移除的是阅读时反复解析 PDF、渲染页面的 CPU 开销。页面内容仍经过后端传输；存储带宽、视频传输与 1000 人负载需另外验证。自动化测试使用真实本地 MySQL、真实 PDF 渲染和模拟对象存储，不代表已验证内网 EDS 连通性。
