# 学习进度可靠保存

- 常规频率不变：视频播放位置约前进 2 秒保存，PDF/图片约累计 5 秒保存；接近阅读完成时提前确认。
- 页面内返回、学习目录、材料切换和顶部返回先等待保存确认。失败保留当前页及内存中的原请求，允许重试。
- 每个播放器的请求串行处理；失败批次原样重试后才提交新批次。文档使用已存在的单次 heartbeat token，后端缓存最近消费结果，避免响应丢失后重复累计。视频携带请求标识，最近一次相同请求重试不再更新时间或累计时长。
- 切入后台、pagehide 和组件卸载使用 keepalive 尝试补报。浏览器关闭/崩溃、断网时不能保证送达；没有引入离线记时或恢复后无条件补计。
- 保存失败时暂停有效计时/视频播放。恢复、重新播放时重新建立时间起点，后端仍以服务器经过时间和学习凭证校验。
- 部署需要后端 V52 迁移，仅增加请求去重字段。先升级后端，再升级前端；旧客户端请求仍可使用。
- 本地测试包括真实 MySQL 的并发重复请求、视频重试不更新时间，以及浏览器模拟接口的短时阅读、失败阻止切换、原批次重试。尚未在远程测试服务器部署，也未做千人压测。
