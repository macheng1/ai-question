# EDS / 阿里云 OSS 连接复用

两个存储适配器均采用延迟初始化的单实例客户端。首次使用时创建，多个业务请求共享 SDK 的线程安全客户端和连接池；未配置且没有被使用的厂商不会因此阻止应用启动。

每次上传结束关闭上传流；读取方仍必须关闭返回的文件流。操作失败或中途关闭下载不关闭共享客户端。应用停止时由 Spring 统一关闭客户端，重复关闭不会重复释放，也不会重新创建。

初始连接池参数（每个应用实例、每个厂商各自生效）：

- 最大连接数 128。
- 连接建立及连接池等待超时 10 秒。EDS 所用 SDK 的连接池等待时间沿用 connectionTimeout。
- Socket 无数据等待超时 60 秒。
- 空闲连接回收阈值 60 秒，连接复用 TTL 5 分钟。
- SDK 错误重试上限 2 次；超时是单次等待限制，不是整个操作总时长。

不需要修改环境变量或数据库。本项保持 EDS 原有签名、TLS 设置，以及阿里云原有私有对象 ACL。

已用两个真实 SDK 连接本地模拟存储，验证连续完整读取复用同一 TCP 连接、中途关闭读取后可以继续访问；并发测试验证只初始化一个客户端。尚未做内网 EDS 或真实阿里云的负载测试。

128 是初始上限，不代表支持 128 或 1000 个在线学员。视频长时间占用连接时可能出现等待；需结合后端实例数、EDS 延迟、视频流量进行压测调整。
