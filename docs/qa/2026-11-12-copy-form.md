# 培训复制改为表单确认后创建

点击列表“复制”只进入 `/profile/trainings/{id}/copy`，读取原培训并预填名称、简介、分类、学习要求、时间和评估题目，不创建培训或复制文件。考试关联清空，学习范围默认为空的指定人员，必须重新选择。材料以只读清单展示，确认保存时复制，复制成功后可编辑新培训材料。

表单点击“确认修改并复制”后调用复制接口，提交 sourceVersion 与 training。后端先校验归属及原培训版本，按企业分配锁、考试 ID 顺序、原培训的顺序加锁；表单保存、名单绑定、文件复制在同一事务内完成。校验或存储失败回滚培训、名单与绑定，并清理已复制的新文件。旧的无请求体复制调用被拒绝。原培训及其文件不变，不创建考试或试卷。

验证：
- 新增用例在旧实现下失败：提交修改名称后返回原名称加副本，确认复现旧接口忽略表单。
- 完整后端 `mvn package`：200 项，199 通过、1 项真实云存储测试跳过，其中 32 项 MySQL 集成测试通过。
- 新增覆盖：最终表单内容及名单保存、只读取原培训不新增、无效表单不新增、文件复制失败回滚培训和试卷绑定并清理新文件、缺少配置拒绝、原培训版本过期拒绝、跨企业复制拒绝。
- 前端 TypeScript 通过；改动文件 ESLint 无错误，列表二维码原有 img 警告 1 条。
- Chrome 本地实测：列表更多→复制直接进入预填表单，无复制确认弹窗；修改名称后离开，出现未保存提示；确认离开后列表仍为原来的 9 条，没有新增测试培训。

本次不增加数据库迁移。本地后端已重启，前端 dev 热更新生效。真实材料服务依赖由测试替身模拟，未在本地用户数据上执行最终复制。

## 补充：复制按预填新增表单处理

- 预填培训时间、学习范围、人员、考试设置和评估题目，清除原记录标记和编辑锁。所有配置可在保存前修改。
- 材料复用新增表单控件：预览、排序、删除、添加文件，以及逐页/统一阅读时长。原材料只加载引用和页配置，不提前创建副本或下载全部文件。
- 最终通过 multipart `/management/trainings/{id}/copy-with-materials` 提交配置、选定材料引用及新文件。服务端验证来源归属/版本、文件索引和页时长，按所选顺序创建新材料；失败回滚培训和新增文件。
- 不继承学习记录、答卷、成绩、反馈。原培训及其材料保持不变。
- 验证包含材料删除/顺序/新上传混排/时长保存、视频混排、拒绝其他培训材料、失败清理、全部材料删除后保存。
- 浏览器检查：培训 68 复制页已预填原日期和范围，显示视频及文档完整操作，PDF 显示 12 页并可打开时长设置。未向用户数据库提交验收副本。
