# 多个培训共用已有考试

本次需求取代原先培训和考试一对一限制。多个培训可关联同一个已有考试，复制培训仍不生成考试/试卷，也不继承考试关联；管理员自行选择已有考试。同一学员不得跨培训重复绑定同一试卷的历史绑定规则保留，考试自身的重考次数不变。

## 变更

- 删除考试已关联其他培训、考试已有活动不能新增关联的全局限制，仍校验考试归属。
- 考试入口按当前学员实际分配的培训校验资格及开始时间，不再要求属于所有关联培训。
- 视频、阅读材料、完成校验和学习日志按培训名单隔离；请求其他培训材料会拒绝。
- 培训的学习范围锁定、解绑/删除保护、材料上传限制只统计本培训学员的活动。其他培训的活动不锁住未使用的培训。
- 考试名册合并并去重；历史自动复制的考试若已被其他培训使用，解绑时保留。
- 考试结果页满意度入口使用当前学员的培训名单，不展示其他培训入口。

## 验证

先添加真实 MySQL 集成用例，旧代码保存第二个培训返回 400，确认复现。修改后在独立 MySQL 8 数据库运行完整 `mvn package`：197 项，196 通过、1 项真实云存储测试跳过；其中 29 项数据库集成测试全部通过。

新增场景覆盖同一考试关联不同培训、不同学员的视频/PDF隔离及越权拒绝、未来培训不阻挡其他培训、只完成自己的材料即可通过学习校验、学习日志隔离、考试名册合并、同学员重复绑定拒绝、其他培训有学习/考试记录时未使用培训仍能解绑和删除。现有复制不增考试/试卷、并发绑定、自动分配和考试重考等测试也通过。

前端 TypeScript 检查通过。无新增数据库迁移，不需修改表结构。业务回归数据仅位于独立测试数据库，本地用户培训和考试未修改。
