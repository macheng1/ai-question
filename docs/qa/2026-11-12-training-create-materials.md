# 新增培训时添加材料

第一步提供视频、PDF、图片选择，支持多选、移除、同类材料排序。文件保存在当前表单内，切换步骤保留；刷新或离开后需要重新选择。视频单个 100MB，PDF/图片单个 20MB，本次提交总计最多 190MB（服务端 multipart 请求上限 200MB）。PDF 每页默认阅读 120 秒，创建后仍可调整阅读时长。

最后一步通过 multipart 创建接口统一保存培训、考试、评估和材料。服务端复用已有文件格式及内容校验，整个创建操作在同一事务中；任意文件失败回滚数据库，已上传对象通过事务回调清理。失败后前端保留文件与表单供修正重试。旧编辑页的已有材料维护能力保留。

验收：新增页面第一步可见两个材料入口，不再提示先保存再上传。MySQL 集成回归包含视频和图片随培训创建、后续无效 PDF 导致整批回滚并清理先前视频。前端类型检查及相关组件 ESLint 通过。未在用户数据库上传测试材料。

## 新增时识别页数并设置时长

选择 PDF/图片时调用管理员鉴权的只读解析接口，复用正式上传的文件校验，返回实际页数，不创建培训或存储对象。表格显示页数；预览 / 时长弹窗支持翻页、统一时长及逐页时长。选中的文件、页数及时间设置保存在当前表单内，最终 multipart 请求按材料顺序提交时长配置，后端重新读取实际文件页数并校验 1–3600 秒及页码完整性，再与培训和材料一起提交。旧表单中尚未识别页数的文件可以通过预览 / 时长补全，避免直接刷新丢失文件。

验证：两页 PDF 在保存前解析为 2 页且没有调用存储服务；保存后对应页分别为 45 秒、90 秒；不完整/无效时长配置导致创建回滚。后端全量 208 项中 207 通过、1 项跳过。TypeScript、相关组件 ESLint、git diff --check 通过。
