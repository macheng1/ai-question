# 培训与考试时间专项检查

范围：培训开放/截止、学习入口与进度写入、考试开始与答题截止、历史记录、学员完成时间、统计时间显示。

## 修复

- 考试接口中的培训时间聚合值曾丢失 JDBC 时区信息，已通过 epoch 毫秒传递，接口输出带时区时间。
- 学员培训列表及材料详情的完成时间存在相同聚合问题，统一转换为 Timestamp 后输出，避免无时区时间与有时区时间混用。
- 新增真实 MySQL 回归：对比数据库培训开始时间与公开考试接口；核验视频及文档完成时间；培训到期后拒绝学习入口、视频进度、文档会话，保留历史详情查询。

## 检查结果

- 学习结束校验使用数据库 CURRENT_TIMESTAMP，覆盖视频和文档入口。
- 考试开始及继续答题使用统一绝对时间；交卷与历史查询不受新增学习入口限制。
- Dashboard 已单独处理聚合 LocalDateTime 的北京时间转 UTC，未重复转换。
- 培训统计明细使用原始 Timestamp，前端明确按 Asia/Shanghai 显示。
- 数据库完整回归：221 项，220 通过、1 跳过，无失败。
- JVM 切换为 UTC 后，真实数据库时间专项回归再次通过。
- 前端 TypeScript 检查通过。

本次未进行所有页面的人工浏览器操作，也未验证生产环境部署；测试使用独立 MySQL 数据库，不修改用户的培训进度。
