# 培训统一学习范围

- 培训关联考试选填，取消独立用途输入；培训范围与基本信息同事务保存。
- TrainingAudienceService 负责范围验证、名单快照和学习资格；AssessmentRosterService 只读取关联培训名单并委托资格校验。
- 考试安排/编辑去除范围配置及废弃预览接口。成绩统计读取培训名单。
- 员工中心按培训名单筛选；H5 根据 assessmentId 选择单独学习或学习后考试，保留续学与计时。
- 无历史迁移、无数据清空；已有学习或答题记录锁定关联与范围。未关联培训的考试保留当前独立考试入口，不新增限制。
- 验证：保存与范围校验、越权、学习门禁、独立/关联流程、前端类型和浏览器。

## 已实现与验证

- 培训保存接口携带 `audience: { type: ALL | DEPARTMENT | USERS, ids: number[] }`，校验失败整笔保存回滚。
- 考试创建/编辑不再接收范围字段，删除独立考试名单预览接口和前端选择器。成绩部门、应考名单和员工培训列表均读取培训名单。
- 同一考试只允许关联一项培训；已有学习或考试记录后，范围及关联不能改变，基础信息仍可保存。
- H5 按 `assessmentId` 决定入口；未关联考试可以完成培训，不出现“待安排考试”。独立培训评估返回培训页。
- 不修改现有数据库表结构、不清空旧数据、不做旧名单迁移。
- 本地 Maven 测试通过；前端 TypeScript 检查通过。涉及页面 ESLint 无错误，考试列表保留两条既有警告（effect 依赖、二维码 img）。
- 实际接口已验证：原子保存、部门/人员名单、范围外访问拦截、材料学习门禁、分页阅读计时、续学、完成培训、答题交卷、应考名单和学习日志。
- 浏览器已验证：范围选择器、考试弹窗无范围选项、培训二维码、390px 手机独立学习完成、关联考试跳转，无运行错误。
