# 图标与组件统一

用户要求：全站不再使用emoji或字符充当图标，优先采用现有Semi UI组件，包括表单控件；保持现有业务逻辑。

实施：
- 全站扫描图标字符、原生交互控件和表单。
- 培训与评估：使用Semi Button/Input/TextArea/Checkbox/Radio/Switch/Upload及Table。
- 考试、试卷、题库管理：替换状态图标、作答与编辑控件。
- 首页、导航、个人中心：替换字符装饰和操作控件，真实品牌图片保留。
- 明确添加semi-icons直接依赖；不存在合适图标时才使用同风格SVG。
- 检查TypeScript、ESLint、生产构建，并浏览器验证表单、锁定状态、答题、移动布局。

边界：HTML结构标签和video媒体元素保留；不改接口或业务规则。纯视觉可逆改动不新增镜像实现测试，以构建和真实交互验证。
