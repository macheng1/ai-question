# 手动培训提醒实施计划

已确认：培训结束时间和考试结束时间独立维护；只做一键邮件提醒，不做自动提醒。培训到期不禁止补学；考试规则保持不变。

1. V39 增加 training.end_at 和邮件发送记录；TrainingService 保存/返回结束时间，前端 Semi DatePicker 编辑。关联考试时提示培训晚于考试结束时间。
2. TrainingReminderRules 独立判定培训/考试逾期原因，满意度不纳入。名单来自 training_audience，覆盖未开始人员；复用学习完成口径；以最后一次考试成绩判定。
3. TrainingReminderService 校验企业所有权，预览返回后台生成请求标识、名单、时间及邮箱状态；手动发送时重查资格，限制批量人数，记录结果。唯一请求标识+员工防止网络重试重复发信。
4. TrainingReminderMailer 隔离 SMTP，缺少配置明确拒绝。配置写入示例、Docker 和部署说明。发送失败可重新打开弹窗再选择发送，不自动重试。
5. 培训更多菜单增加一键提醒，独立业务弹窗直接使用 Semi Banner/Table/Modal，显示规则、缺邮箱状态、上次发送时间和逐人发送结果。
6. 单测验证时间边界、两类独立原因、缺邮箱、权限、重复请求；本地假 SMTP 验证实际邮件和接口/弹窗；前端类型检查、后端测试。
