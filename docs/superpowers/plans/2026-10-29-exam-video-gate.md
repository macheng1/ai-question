# 考前视频学习与管理预览

依据用户明确流程：培训视频在管理端可预览；取消独立学习入口；考试入口按考生身份判断关联视频是否全部看完，看完才开始考试，并保留原来的时间、续考、次数与成绩逻辑。

实现：
- Semi VideoPlayer + Modal 管理预览，认证 Blob 加载，错误重试与资源回收。
- 姓名和手机号识别考生，数据库保存独立观看进度。考试关联多个培训时检查全部视频。
- 考试入口先校验时间、资格，再学习；仅新答题实例强制视频条件，已有进行中记录保持续考。
- 客户端禁止跳过未看片段，服务端验证进度、完成条件和开始资格。视频期间不创建考试 attempt，不耗考试时长。
- 旧培训入口重定向考试，结果页按关联关系展示评估，无需 trainingId 查询参数。
- 修正 Semi Input 外层多余 padding；使用正式主按钮；去掉原本未绑定保存的工种字段。

验证：类型检查、生产构建、后端回归；浏览器使用培训3/考试4原有视频与真实题目、新测试姓名“视频门禁验收1029”，观看完成后创建 attempt7，答题3题交卷30/30；未观看测试身份直接 start 被拒绝。管理端预览播放正常。

边界：普通浏览器学习记录不证明本人注意力。当前视频时长由播放器上报，严格防作弊需服务器解析媒体时长与更严格身份验证，非本次身份体系改造范围。
