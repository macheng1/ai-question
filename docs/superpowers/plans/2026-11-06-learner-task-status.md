# 员工培训与考试任务状态

- 以 training_audience 为任务来源，未学习/未答题也显示；培训状态与考试状态分别计算。
- 培训：未开始、学习中、学习完成，显示材料完成数、进度、有效时长和时间记录。
- 考试：未开始、待学习、待考试、答题中、已通过、未通过、结果待公布、已结束；补考单独按现有次数及时间规则计算。
- 新增员工 ID 关联与分配/学习起始/完成时间；历史关联仅通过已有企业培训名单准确回填，不猜测账号。
- 保留考试每次答题历史与成绩公布限制，新增我的考试任务视图及任务详情。
- 学习与扫码继续沿用原流程；员工记录按 ID 查询，不依赖当前姓名、手机号。
- UI 使用 Semi 默认组件，PC/手机布局；验证状态规则、企业隔离、未开始任务可见、记录与详情、H5 入口。
