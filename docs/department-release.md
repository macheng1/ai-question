# 部门与员工：使用与发布说明

## 使用

- 个人中心新增「部门与员工」。一级部门；每名员工一个部门；同一管理账号下手机号唯一。
- 部门和员工可新增、编辑、停用、恢复，员工可调整部门。已停用部门不参与新考试选人。
- 考试参考范围支持所有人、指定部门、指定人员。受限考试保存范围和应考名单快照。
- 名单按保存时姓名、手机号和部门匹配；后续名册改名、调部门、停用不自动改已安排考试。
- 普通编辑不重建名单；已有学习或参考记录后锁定名单。
- 历史受限考试缺失名单时，管理员可一次性补齐受限名单，必须覆盖所有已学习/参考的姓名与手机号；不得改成不限范围，补齐后恢复锁定。
- H5 资格查询、学习、视频进度、开始考试、续答和交卷校验名单。不限范围流程不变。
- 成绩页展示部门并支持筛选；名单概览按人统计应考、已考、未考，至少交卷一次记已考，重考不增加人数。
- 姓名手机号匹配不等同本人身份认证，本期没有新增短信或员工登录。

## 发布

- 后端包含新增 Flyway V28，新增部门、员工、考试范围关联、应考名单四张表。沿用现有数据库权限与配置，无新增环境变量。
- 先备份数据库，再部署后端并确认 V28 成功，最后部署前端。
- 本次只在本地 MySQL 验证迁移，未操作远程 dev 数据库。
- 发布前检查历史 DEPARTMENT/USERS 考试：旧版本只保存范围标记，没有名单。无名单时新版本拒绝新的参考请求，须由管理员处理，不应静默改成所有人。

只读排查 SQL：

```sql
SELECT a.id,a.name,a.candidate_scope,
 (SELECT COUNT(*) FROM assessment_participant p WHERE p.task_id=a.id) participant_count
FROM assessment_task a
WHERE a.candidate_scope IN ('DEPARTMENT','USERS')
 AND NOT EXISTS(SELECT 1 FROM assessment_roster r WHERE r.task_id=a.id);
```

## 本地验收

- 实际 API：部门员工维护、同账号手机号唯一、部门预览去重、跨账号读写拒绝、空名单创建回滚、修改失败回滚、名单快照、学习后锁定、重考、不限范围兼容、旧无名单考试补配。
- 浏览器：在部门下新增员工，安排考试选部门，390px H5 完成三题（单选、多选、判断）并取得30/30分；成绩页应考2人、已考1人、未考1人。
- 验收数据仅在本地，以「部门验收」标记；未改变现有题库题目。
