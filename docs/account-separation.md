# 企业管理员与员工账号分离

## 本次范围

- 企业账号沿用 app_user；员工使用 organization_employee。登录页分企业管理员、员工入口，菜单与页面守卫统一使用 accountType。
- 管理端：概览、培训、题库、试卷、考试、部门与员工。
- 员工端：我的培训、培训记录、考试记录、我的错题、满意度评估；头像菜单进入账号设置。
- 员工初始密码 12345678，保存 BCrypt 哈希。管理员可重置，员工可修改自己的密码。
- 管理接口实时验证身份；同数字 ID 的员工与管理员互不混用。停用员工或所属企业后，既有员工令牌也不能继续访问。
- 员工查询按所属企业和本人筛选；未公布成绩时不显示成绩及错题答案。
- 首页进入工作台，旧公共题库、自测、有偿出题、资讯、帮助页面转到工作台；管理端题库保留。
- 公共扫码培训、学习、考试流程保持现有规则，本次未新增强制员工登录。

## 数据库发布

使用包含 Java migration 的完整后端构建产物，由 Flyway 自动执行：

- V36：员工邮箱、密码哈希与初始密码（前序变更）。
- V37：员工手机号全局唯一；工号、数据来源；外部身份映射；满意度评估员工身份字段。

上线前备份数据库，检查重复手机号：

```sql
SELECT phone, COUNT(*) FROM organization_employee GROUP BY phone HAVING COUNT(*) > 1;
```

重复时 V37 会停止，不会自动合并账号或记录；应先核实处理后再迁移。不要只拷贝 SQL 文件而遗漏 Java migration。本次没有新增必填环境变量，沿用数据库、Redis、JWT、OSS 配置。

## 泛微同步预留

organization_external_identity 按企业、来源系统、实体类型关联外部 ID 与本地员工/部门 ID，并记录源数据更新时间、最近同步时间。员工预留 employee_no、data_source。实际同步、定时任务、单点登录暂未实现，待确认接口版本再接入。

## 兼容边界

现有学习及考试记录仍通过原流程的姓名、手机号关联到员工中心。修改姓名或手机号后，旧记录不会自动迁移到新资料；本次未改变历史归属规则。稳定关联需要后续单独核实、迁移历史数据并为学习会话绑定员工 ID。

品牌沿用“智企云考”及现有 Logo，待提供新名称、素材后更换。
