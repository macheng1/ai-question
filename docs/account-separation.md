# 企业管理员与学员身份

## 当前规则

- 登录页仅提供企业管理员密码登录。管理员使用 app_user，密码修改不变。
- 员工保存在 organization_employee；新增、编辑员工不设置密码，也不提供重置密码接口。
- 学员从培训/考试二维码或链接进入，填写姓名和手机号。后端根据入口所属企业匹配在用员工，并校验培训名单，生成 EMPLOYEE 身份凭证。
- 姓名和手机号只是名单核对，并非手机号持有权验证。当前按免密码参训要求实现；如以后需要防冒名，可增加验证码或企业单点登录。
- 管理员与学员凭证分开保存；管理员测试 H5 不会覆盖管理端登录。
- 学习、答题、成绩和评估完成后返回 `/learner`，显示我的培训、培训记录、考试记录、我的错题、满意度评估及员工资料。
- 学员中心只查询本人所属企业的数据，不提供管理菜单和密码设置。

## 身份接口与校验

- `POST /learner/session`：type 为 TRAINING/EXAM，提交入口 id、name、phone，返回学员凭证。
- `GET /learner/me`：读取当前在用员工资料。
- `/public/exams` 和 `/public/courses` 中，公开说明不返回试题；答卷请求必须携带学员凭证，答卷归属按员工 ID 与企业校验。
- 学习上报同时校验学员身份与学习凭证归属。原生视频/图片内容请求使用学习凭证，并实时验证其员工在用状态。
- 满意度评估和学员记录使用学员凭证；管理接口只接受管理员身份。
- 切换学员时清理当前浏览器的答题草稿；答题草稿按答卷编号区分。
- 员工姓名、手机号由管理员维护；停用员工/企业后，既有学员凭证无法继续访问。
