# 页面布局检查（2026-11-03）

按当前本地 dev 工作区检查。布局优先使用页面内 Tailwind；交互控件直接使用 Semi UI。此清单记录布局验收，不代表业务全流程回归或已发布。

## 修复内容

- Card 的留白、排列移到内容容器，避免被 Semi 默认样式抵消。
- 页面网格按实际列数设置，去掉 24 列与大 gap 组合造成的手机端撑宽。
- 列表、表单采用 flex/grid gap，避免子组件默认 margin 重置导致间距丢失。
- 标题字号在页面局部明确指定；修正 H5 结果、题目解析、培训标题过大。
- 手机端网站导航使用 Semi Dropdown；桌面保留 Semi Nav。
- 弹窗在所在组件设置最大宽度及内容滚动，保留标题和底部操作。
- 我的考试改为 Semi Table，修复表头与数据列不对齐。
- 分类、题目和成绩表格只保留 Semi 空状态，去掉重复提示。
- 修复个人中心入口卡片行内显示、组卷顶部标签挤压、注册验证码换行、评估编辑选项换行。
- 修复首页按钮高度不一致、培训新建按钮断行、自测搜索框固定宽度、H5 答题底部按钮未铺满。
- 移除题目表单中未启用的标签输入框，清除相应全局隐藏规则，避免残留空灰框。
