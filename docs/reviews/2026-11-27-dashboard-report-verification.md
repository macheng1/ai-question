# 概览学员筛选与 PDF 报告验收

## 功能与影响范围
- 前端概览新增学员筛选及 PDF 下载，个人信息使用当前部门；统计仍使用培训分配时部门。
- 学时汇总、课程明细、学习日志、未完成名单、Excel、逾期全选/通知继续传递 employeeId。
- PDF 后端复用 DashboardService 汇总，培训表包含所有匹配课程；不使用 UI 分页或明细状态。
- PDF 文字可搜索，字体内嵌；复用 DurationText，与原 Excel 时长格式一致。
- 不涉及数据库结构迁移、学习进度写入、视频、EDS 配置变更。既有隐藏进行中培训一键提醒改动保留。

## 验证结果
- 后端全量 Maven：359 项，357 通过，0 失败/错误，2 跳过（TrainingOssLiveTest、ResetBusinessDataMigrationTest）。
- 其中 MyBatisMigrationIntegrationTest 79 项通过，独立 Docker MySQL 8 测试库；未操作生产库。
- 前端 27 项测试通过；TypeScript 检查与 Next.js 生产构建通过。
- PDF：85 行跨页表格、中文/长名称、25 小时以上时长、无数据/无分母、重复表头和页码。
- 筛选：同名不同员工、无记录、无效参数、时间范围、部门与员工交集、调岗前历史归属、跨企业数据隔离。
- 报告：12 场接口测试验证超分页完整输出；无登录拒绝、跨企业筛选拒绝、错误日期拒绝。
- 通知：选中其他学员记录与 employeeId 不一致时拒绝，邮件 mock 确认没有实际发送。

## 浏览器端实际下载校验
- 本地演示学员 A：5 场培训，4 场学习中，1 场未开始；个人 PDF 为 21分15秒。
- 实际下载学习日志 Excel：4 条该学员记录，有效秒数合计 1275，与 PDF 一致。
- 学时汇总仅显示该学员；点击课程明细仅显示该学员 1 人次；重置恢复 18 场/33 人次。
- 实际下载企业 PDF 包含全部 18 场课程及 28小时49分4秒，与页面一致。
- PDF 渲染图片已检查首页、趋势、培训表和口径页，中文字形与分页正常。

## 环境说明
首次全量测试 EDS localhost 模拟服务被本机 Java 代理转发，6 项失败。只对测试命令设置 localhost/127.0.0.1 的 nonProxyHosts 后，全量重跑通过；未修改系统代理或业务存储配置。
复测还修正了测试夹具固定用户名导致重复运行冲突的问题，改为唯一测试名称。

## 部署
前后端都需部署。字体随后端资源打包，无需系统安装字体，也无需额外浏览器服务。不含提交或推送。
