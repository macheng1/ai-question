# Report font

Noto Sans SC, SIL Open Font License 1.1 (see OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
NotoSansSC-Regular.ttf is the weight-400 static instance of NotoSansSC[wght].ttf,
created using fontTools.varLib.instancer. Glyph coverage is retained; PDFBox embeds
only the glyphs used by each report. This font is bundled so Linux containers do
not depend on system fonts or external network access when exporting reports.
